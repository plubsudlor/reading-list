## 1. ภาพรวมแอป
Reading List เป็นเว็บแอปสำหรับบันทึกหนังสือที่อยากอ่าน กำลังอ่าน และอ่านจบแล้ว ใช้ Node.js + Express เป็น backend
และ HTML/CSS/JavaScript เป็น frontend โดย frontend เรียกเฉพาะ API ของตัวเองด้วย `fetch()`

## 2. การออกแบบ Resource
Resource: `books` (เก็บในไฟล์ JSON)

| Field | ชนิด | บังคับ | คำอธิบาย |
|---|---|---|---|
| id | number | auto | รหัสหนังสือ (max id + 1) |
| title | string | ✅ | ชื่อหนังสือ |
| author | string | ✅ | ผู้แต่ง |
| category | string | | หมวดหมู่ |
| status | want/reading/read | | สถานะการอ่าน (default want) |
| rating | integer 0-5 | | คะแนน |
| createdAt | ISO date | auto | เวลาที่เพิ่ม |

## 3. การออกแบบ REST API
| Method | Path | ความหมาย | สำเร็จ | ผิดพลาด |
|---|---|---|---|---|
| GET | /api/books | ดึงทั้งหมด (กรองด้วย ?status, ?category, ?q) | 200 | - |
| GET | /api/books/:id | ดึงเล่มเดียว | 200 | 404 |
| POST | /api/books | เพิ่มรายการ | 201 | 400 |
| PATCH | /api/books/:id | แก้ไขบาง field | 200 | 400, 404 |
| DELETE | /api/books/:id | ลบรายการ | 204 | 404 |

**เหตุผลการออกแบบ**
- ใช้ชื่อ resource เป็นพหูพจน์ (`/books`) และใช้ HTTP method บอกการกระทำ
- ใช้ query string สำหรับกรอง และ route parameter สำหรับระบุเล่ม
- เลือก PATCH เพราะแก้ไขเฉพาะ field ที่ส่งมา (เช่นเปลี่ยนเฉพาะสถานะ)
- ตรวจข้อมูลที่ฝั่งเซิร์ฟเวอร์ (`validate.js`) ตอบ 400 พร้อมรายการข้อผิดพลาด
