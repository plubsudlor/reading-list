วิธีติดตั้งและรัน

npm install
npm run dev      # รันแบบ auto-restart เมื่อแก้ไฟล์
# หรือ
npm start        # รันปกติ

จากนั้นเปิด http://localhost:3000

REST API Endpoints

MethodEndpointคำอธิบายStatus
GET/api/booksดึงทั้งหมด กรองด้วย ?status= ?category= ?q=200
GET/api/books/:idดึงเล่มเดียว200 / 404
POST/api/booksเพิ่มหนังสือ201 / 400
PATCH/api/books/:idแก้ไขหนังสือ200 / 400 / 404
DELETE/api/books/:idลบหนังสือ204 / 404

ภาพหลักฐานการทำงาน

1) หน้าเว็บ แสดงรายการ / ฟอร์ม / ตัวกรอง

2) ผลทดสอบ API ทุก endpoint (200 / 201 / 204 / 400 / 404)
